# EVACUFLOW — Final Website Prototype

## Run
1. Install Node.js (18+ recommended).
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal in that folder and run:

```bash
npm install
npm run dev
```

5. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Included
- Dashboard and scenario setup
- Representative university, school, and hospital campus layouts
- Editable React Flow graph
- Any graph node can be selected as affected area or destination
- Destination comparison using Edmonds–Karp
- Algorithm iteration visualization
- What-if capacity/blocked-route analysis
- Results report and Print / Save as PDF
- LocalStorage persistence

## Prototype limitation
The layouts and capacities are illustrative, not live or verified geographic data. Maximum flow is not proof of physical safety. Verify actual hazards, accessibility, occupancy and destination safety independently before any real-world use.
